# Design

## Context

当前 Gmsh 只输出 `.msh` 和网格预览；CalculiX 入口只支持用户上传 `.inp`，没有从结构模型生成三维分析输入，也没有读取 `.frd` 应力结果。报告模块只渲染运行清单和 JSON。

## Goals / Non-Goals

**Goals:**

- 从现有 H 型钢实体网格生成可执行的 CalculiX 静力输入。
- 解析真实 `.frd` 数值结果，生成可审计的结果摘要。
- 生成 von Mises 应力云图并接入 Streamlit 与报告。
- 保持运行目录隔离、路径校验和“不可用不伪造完成”的约束。

**Non-Goals:**

- 不实现通用 CAD 网格器或任意单元类型转换。
- 不替代规范验算、接触分析、非线性分析或正式审图。
- 不上传求解运行产物，只上传测试图纸和代码。

## Decisions

- 使用现有 Gmsh 四面体网格和 `meshio` 转换为 CalculiX C3D4/C3D10；避免重新实现网格拓扑。
- 使用本机 CalculiX，发现顺序沿用 `CIVILFEM_CALCULIX`、`ccx`、`calculix`；失败时返回明确状态。
- 采用单元静力模型：固定最小 X 面节点，自由端最大 X 面施加由模型 `N/V/Mx` 组成的等效载荷；报告明确该边界假设。
- `.frd` 解析只支持本次生成的节点位移和应力记录；解析器输出统一 JSON，不把原始文本直接当结果。
- 应力云图使用 PyVista 离屏渲染，结果数组挂到网格点或单元，显示 `von Mises (MPa)` 色标。
- 报告使用 HTML 原生表格、摘要卡片和图片链接；Markdown 保留同一数据结构。

## Risks / Trade-offs

- [CalculiX 输入边界与载荷映射可能不适用于任意模型] → 仅对当前 H 型钢梁路径启用，并在报告写明假设。
- [`.frd` 格式存在版本差异] → 只解析已知记录类型，失败时报告原因为解析错误。
- [离屏渲染依赖图形环境] → 保留无云图但有数值结果的状态，页面显示依赖缺失。
- [大网格耗时或内存高] → 沿用现有网格单元上限，限制结果文件和报告摘要大小。

## Migration Plan

1. 增加 FEM 适配器和测试，保持现有 OpenSeesPy/CalculiX 上传流程兼容。
2. 将新结果字段作为可选字段写入运行清单。
3. 更新 GUI 使用新 FEM 运行结果；旧运行清单仍可生成基础报告。
4. 测试通过后提交代码和 `examples/cad_samples`，推送 `main`。
