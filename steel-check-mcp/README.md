# steel-check-mcp

**钢结构构件校核工具集（GB 50017-2017）+ MCP 暴露 + 评测集**

把中国钢结构设计标准的构件校核能力，做成 Agent 可直接调用的确定性工具。
零外部依赖（MCP 层除外），结果可复现、可追溯、可评测。

```bash
python cli.py --demo                 # 30 秒看到效果
python eval/run_eval.py              # 跑评测集，输出偏差报告
python mcp_server.py                 # 起 MCP Server（需 pip install mcp）
```

---

## 为什么做这个

给大模型接一个"能算对钢结构"的工具，难点不在算，在于：

1. **结果要能判定对错** —— 不是给一段"看起来合理"的文字，而是给出校核值、限值、应力比、结论
2. **结论要能追溯** —— 每一条都带规范条文号，工程师才敢用
3. **能力边界要说清** —— 工具描述里写明不适用场景，避免 Agent 越界调用

## 架构

```
                     ┌──────────────────────────────┐
   构件参数 JSON  →   │  steelcheck.py  校核核心       │
   Agent 工具调用 →   │  · 截面几何特性（解析计算）     │
                     │  · 材料强度设计值              │
                     │  · 强度 / 稳定 / 长细比校核     │
                     └──────────────┬───────────────┘
                                    │ 结构化结果
                    ┌───────────────┼───────────────┐
                    ▼               ▼               ▼
              cli.py           mcp_server.py    eval/run_eval.py
              （人可复现）      （Agent 调用）    （可靠性验证）
```

**核心层与暴露层分离**：校核逻辑与协议、CLI 无关，因此 CLI、MCP、未来的 HTTP API
共用同一份实现，评测也直接跑核心层。

## 输出格式

每个校核项都返回结构化字段，而不是自然语言：

```json
{
  "item": "axial_stability",
  "clause": "7.2.1",
  "demand": 178.67,
  "capacity": 305.0,
  "unit": "N/mm²",
  "ratio": 0.586,
  "verdict": "PASS",
  "note": "λ=79.0, φ=0.5740, b 类截面"
}
```

这样 Agent 拿到结果后可以自己决策：应力比 0.95 就要提示"接近限值"，
`verdict=FAIL` 就要触发重新选截面，而不需要去解析一段文字。

## 已实现的校核项

| 校核项 | 条文 | 说明 |
|---|---|---|
| `bending_strength` | 6.1.1 | 抗弯强度 σ = Mx/(γx·Wnx) + My/(γy·Wny) ≤ f |
| `shear_strength` | 6.1.3 | 抗剪强度 τ = V/(hw·tw) ≤ fv（工字形近似） |
| `axial_stability` | 7.2.1 | 轴心受压整体稳定 N/(φA) ≤ f，φ 按附录 D 拟合式计算 |
| `slenderness` | 7.4.6 | 容许长细比 λ ≤ [λ] |
| `lateral_torsional_buckling` | 6.2.2 | 受弯整体稳定 Mx/(φb·Wx) ≤ f（φb 需外部传入） |

## 精度说明（重要）

截面几何特性由尺寸**解析计算**，不查型钢表。对**焊接组合截面**是精确的；
对**热轧型钢**因翼缘根部有圆角，与型钢表存在约 1~3% 偏差：

| 参数 | 解析计算 | HW300×300×10×15 型钢表 | 偏差 |
|---|---|---|---|
| A | 11,700 mm² | 11,980 mm² | −2.34% |
| Ix | 1.9933×10⁸ mm⁴ | 2.0400×10⁸ mm⁴ | −2.29% |
| Iy | 6.7523×10⁷ mm⁴ | 6.7500×10⁷ mm⁴ | +0.03% |
| Wx | 1.3289×10⁶ mm³ | 1.3600×10⁶ mm³ | −2.29% |

选择解析计算而非查表，理由是：**可处理任意焊接组合截面**（钢结构设计里大量使用），
且不存在型钢表数据录入错误的风险。用于热轧型钢时需要接受上述偏差，
或在 `steelcheck.py` 中扩展查表模式。

## 评测

`eval/cases.json` 中每条基准值都来自**独立来源**（规范例题、设计手册、手算），
不由本程序生成 —— 否则就是自证循环。

```bash
python eval/run_eval.py --json eval/report.json
```

评测过程确实捕获过一个真实错误：E04 的基准值最初把 φ 写成了 Q355 的值（0.5740），
但该算例钢材是 Q235，λn 更小、φ 应为 0.6945。**φ 随 fy 变化，换牌号必须重算 λn** ——
这类错误靠人工复核很容易漏掉。

## 能力边界（不做什么）

本工具**只做构件层面校核**，以下场景需要其他手段，请勿用本工具回答：

- 节点板、焊缝、螺栓群、柱脚 —— 属于节点验算，规范第 11 章
- 局部稳定（板件宽厚比）—— 计划中，尚未实现
- 疲劳、抗震构造措施 —— 未实现
- 非双轴对称截面（箱形、圆管、角钢、T 形）—— 未实现
- 应力集中、局部屈曲、往复滞回 —— **属于有限元分析范畴**，本工具不涉及
